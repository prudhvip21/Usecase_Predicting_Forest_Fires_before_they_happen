# Predicting Forest Fires

Predict the area burned by forest fires from weather and fire index data.

## Approach

- Exploratory analysis of weather and seasonal patterns
- Linear Regression, SVR and Decision Tree regressors

## Results

R-squared values were negative in the saved notebook output, meaning these models did not beat predicting the average. Burned area is hard to predict from these features alone.
